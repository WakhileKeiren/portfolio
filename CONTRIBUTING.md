# Contributing

Thanks for your interest in this project. This is a personal portfolio, so I'm not actively seeking code contributions — but I welcome feedback, bug reports, and suggestions.

---

## How to Help

### 🐛 Report a Bug

Found something broken? Open an issue with:

- What you expected to happen
- What actually happened
- Your browser and device
- Screenshots if helpful

### 💡 Suggest an Improvement

Have an idea? Open an issue with the label `enhancement` and describe:

- What you'd like to see
- Why it would help
- Any examples or references

### 📝 Typo or Copy Fix

Spotted a typo? Open an issue or submit a small pull request.

---

## What I'm Not Accepting

- **Design overhauls** — the visual identity is intentional
- **Framework migrations** — the site stays vanilla HTML/CSS/JS
- **Analytics or trackers** — the site is intentionally tracker-free
- **Third-party dependencies** — no npm, no CDN scripts, no build tools
- **Auto-generated content** — everything is hand-crafted

---

## Pull Request Process

If you do submit a PR:

1. Fork the repo
2. Create a branch: `fix/short-description` or `feat/short-description`
3. Make your change
4. Test on mobile (360px) and desktop (1440px)
5. Verify no console errors
6. Submit the PR with a clear description

I'll review as soon as I can.

---

## Code Style

- 2-space indentation
- Semantic HTML (`<button>` not `<div onclick>`)
- CSS variables for colors, spacing, typography
- Comments for anything non-obvious
- No inline styles where classes exist
- No `!important` unless there's a good reason
