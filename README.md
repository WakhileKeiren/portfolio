# Wakhile Keiren Mavimbela — Portfolio

> I design systems, stories, and solutions.

The personal portfolio of **Wakhile Keiren Mavimbela** — a nurse, designer, and digital health builder based in Eswatini. This site collects my work across digital health, brand identity, social impact, and visual communication.

🔗 **Live site:** [wakhilekeiren.github.io/portfolio](https://wakhilekeiren.github.io/portfolio/)

---

## 🎨 About This Site

A hand-coded portfolio — no frameworks, no templates, no drag-and-drop builders. Built with HTML, CSS, and vanilla JavaScript, then deployed on GitHub Pages.

The design language is intentional:

- **Deep navy** (`#0B2B3D`) — stability, trust, calm
- **Warm gold** (`#F9A826`) — warmth, hope, energy
- **Soft off-white** (`#F5F9FF`) — breathing room, clarity
- **Fraunces** (headings) + **Inter** (body) — character + readability

---

## 📂 What's Inside

- **Hero** — a statement of intent
- **About** — who I am, what I do, and where my work sits
- **Work** — a filterable gallery across digital health, apps, branding, and certificates
- **Services** — what I offer clients and collaborators
- **Skills** — the tools and disciplines I work with
- **Writing** — my Substack essays on mind, medicine, and meaning
- **Contact** — every way to reach me
- **Footer** — archives, code, and links

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox, clamp)
- Vanilla JavaScript (Intersection Observer, filter logic, lightbox, mobile menu)
- Google Fonts (Fraunces + Inter)
- GitHub Pages (hosting)

**Zero dependencies. Zero build step. Zero trackers.**
