# Security Policy

## Reporting a Vulnerability

If you discover a security issue with this site, please **do not open a public GitHub issue**.

Instead, contact me privately:

🔗 [Linktree contact](https://linktr.ee/wakhilekeirenmavimbela)

Please include:

- A clear description of the issue
- Steps to reproduce it
- What browser and device you used
- Screenshots (if safe to share)

You'll get a reply within 72 hours.

## Scope

This is a static portfolio website. There is:

- No backend
- No database
- No user accounts
- No cookies
- No tracking
- No analytics
- No third-party scripts (beyond Google Fonts)

The attack surface is intentionally minimal.

---

## What's Protected

Even though this is a static site, I take the following seriously:

- **No user data collection** — the site does not collect, store, or transmit personal information
- **HTTPS only** — GitHub Pages serves everything over TLS
- **No external dependencies** — the site loads only Google Fonts and nothing else
- **No forms with backend submission** — contact happens via external links (WhatsApp, email, socials)

---

## Data Privacy

This site does not collect any personal data.

- No cookies
- No localStorage beyond visitor preferences (if any)
- No server logs beyond what GitHub Pages logs by default
- No analytics scripts (no Google Analytics, no Plausible, no Fathom)

If you click external links (Instagram, WhatsApp, Substack, etc.), those platforms have their own privacy policies.

---

## Third-Party Services

The only third-party service loaded by this site is:

- **Google Fonts** — loads Fraunces and Inter fonts. Google may log the request. See Google's privacy policy.

If you want to eliminate even that, you can self-host the fonts.

---

## Supported Versions
